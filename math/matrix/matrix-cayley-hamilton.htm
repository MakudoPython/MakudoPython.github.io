ケーリー・ハミルトンの定理

定理の主張

2次正方行列 A = ((a, b), (c, d)) について、次の等式が成り立つ。

A² − (a+d)A + (ad−bc)E = O

（E は単位行列、O は零行列）

証明

A − aE = ((0, b), (c, d−a))
A − dE = ((a−d, b), (c, 0))

この2つの積を計算すると

(A−aE)(A−dE) = ((bc, 0), (0, bc)) = bcE

一方で展開すると

(A−aE)(A−dE) = A² − (a+d)A + adE

よって

A² − (a+d)A + adE = bcE
A² − (a+d)A + (ad−bc)E = O
